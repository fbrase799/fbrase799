# Infrastructure & DevOps

My view: infrastructure is part of the product. If it cannot be **rebuilt, observed, and promoted** the same way in every environment, the architecture is incomplete.

I focus on containerized runtimes and cloud delivery that keep local and production close:

* **Azure** (including Container Apps)
* **Terraform** for infrastructure as code
* **Docker** / **Kubernetes**
* **GitHub Actions** with secure cloud auth (e.g. OIDC)

Both engineering showcases ship with Docker Compose locally and Azure Container Apps in the cloud — same images, deliberate CI/CD. That is the standard I aim for: automation that supports architecture, not a separate “ops” afterthought.

**Keywords:** Azure · Terraform · Docker · Kubernetes · GitHub Actions
