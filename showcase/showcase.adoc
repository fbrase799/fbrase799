== Engineering Knowledge Assistant

An engineering Q&A demonstrator that compares a curated local knowledge base with current public web information. LangGraph orchestrates retrieval, web search and LLM synthesis within explicit execution limits.

image::knowledge-assistant.png[Engineering Knowledge Assistant showing a hybrid Q&A result,pdfwidth=88%,align=center]

*Architecture & technologies*

* *Frontend:* React, TypeScript, Vite — response view and an SSE-based execution timeline
* *Backend:* FastAPI, LangGraph, LangChain — stateful orchestration with conditional routing
* *Retrieval:* FAISS and FastEmbed MiniLM — shared read-only document corpus
* *Generation:* Tavily web search and Azure OpenAI — bounded search and synthesis calls
* *Deployment:* Docker Compose and Azure Container Apps

*Engineering focus:* Hybrid RAG and web-based Q&A, traceable execution, explicit request budgets, and source validation.

== Vehicle Configurator

A live, multi-step vehicle configuration application combining a Java/Spring Boot REST backend with a Vue-based interactive frontend.

image::vehicle-configurator.png[Vehicle configurator with interactive 3D car preview,pdfwidth=88%,align=center]

*Architecture & technologies*

* *Frontend:* Vue 3, Vite, Three.js — interactive 3D vehicle preview and real-time price updates
* *Backend:* Java 25, Spring Boot 4, JPA/Hibernate — REST API, server-side pricing and order submission
* *Persistence:* SQLite embedded in the backend
* *Deployment:* Docker Compose and Azure Container Apps with separate frontend and backend containers
* *Delivery:* GitHub Actions CI/CD with OIDC-based Azure deployment

*Engineering focus:* Full-stack software architecture, separation of concerns, reproducible container deployment and automated delivery.
